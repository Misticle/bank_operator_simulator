# Лог развития и обсуждения ТЗ (TZ Development Log)

Документ фиксирует эволюцию требований и архитектурных решений проекта.

### Запись 1: Анализ исходного черновика (2026-11-23)
* **Исходные данные:** Черновик ТЗ из `simulator_bank_operator_draft.md`.
* **Выявленные аспекты для доработки:**
  1. *Хранение капитала банка:* Первоначально планировался отдельный исполняемый файл `back_money_ammount.py`. Выявлена опечатка в нейминге и антипаттерн мутации исходного кода Python для хранения данных. Принято решение вынести данные в файл состояния (`reserves.txt`), а в коде инкапсулировать резервы как свойство класса `Bank`.
  2. *Организация кода:* Отказ от свалки классов в одном файле `classes.py` в пользу доменной структуры (`models.py`, `security.py`, `exceptions.py`).
  3. *Вход в систему:* Уточнено, что оператор уже авторизован за своим рабочим терминалом, постоянный ввод логина/пароля не требуется.
  4. *Админские действия:* Пароль директора требуется контекстно — только при вызове критических операций (паттерн Декоратор).
  5. *Экономика банка:* Банк стартует с солидного капитала (константа 5 000 000 руб.), фокус на корректности учета, а не на механиках тайкуна.
  6. *Интерфейс:* Разделение на два этапа — сначала отладка через консоль/`print`, затем возможное подключение интерактивного TUI со стрелочками.
  7. *Налоговая проверка:* Перенесена в бэклог 4-го этапа, чтобы не усложнять разработку базового ядра (MVP).
